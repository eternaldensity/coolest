# v0.7 Plan — Hosts as Dungeons

> Status: **host dungeon core landed.** Zones, accounts, files, and the
> read/crack/decompile/takeover verbs are in sim, fuzzed, and surfaced in
> the Deck inspector. Banking quorum, mirrored records, and mailer
> hardening remain as a follow-up (see §6) because they require the
> LedgerService refactor and are larger than one session.
>
> `./gate.sh` green at 264 test executions. `./nightly.sh` pending.

## 1. Goal

Make a host a place you enter and operate inside, not just an arena:
zones gate visibility, accounts gate control, files are loot, and the
existing kinds (Scanner, Cracker, Editor, Cloner, Killer) gain real
targets to act on.

## 2. Landed (this phase)

### 2.1 Data model (`sim/src/deck.rs`)

- `MemZone { Public, Shared, Private, AccessPublic, AccessPrivate }`
  with `name()` and serde default `Public`.
- `Account { id, handle, crack_difficulty, admin, home }`.
- `HostFile { name, size_sectors, content, executable }`.
- `Host` fields (all `#[serde(default)]`):
  - `zones: Vec<MemZone>` (one per RAM cell, default Public).
  - `accounts: BTreeMap<u64, Account>` (default guest + admin).
  - `files: BTreeMap<String, HostFile>` (default readme + log).
- `Host::new` seeds a guest account, an admin account, and two files.
- Methods: `zone_at`, `set_zone`, `accounts`, `accounts_mut`, `files`,
  `files_mut`, `read_file`, `account`.
- `HostFile::size_sectors` uses `div_ceil` for whole-sector accounting.

### 2.2 Verbs (`sim/src/world.rs`)

| Verb | Requires | Effect |
|---|---|---|
| `DeckListFiles` | host present | Lists file names (logged as `file:` events). |
| `DeckReadFile { name }` | host present | Reads a file (logged as `read:`/`content:`). |
| `DeckDecompile { x, y, file }` | Editor on host | Reads a file and logs `decompiled:`. |
| `DeckTakeover { x, y }` | Killer adjacent to a foreign head, mindpower 5+ | Flips ownership of the enemy head. |

Existing verbs (`DeckCrack`, `DeckPatch`, `DeckOverwrite`, `DeckClone`,
`DeckScan`, `DeckConnect`, `ScrubLog`) already cover the rest of the
dungeon surface and now have zone/account/file targets to act on.

### 2.3 GUI

- Host header chips: `files N`, `accounts N`.
- Deck inspector selection card: `zone {name}` chip.
- Deck arena cells paint a zone-colour corner marker for non-Public zones.
- `street_map` untouched structurally.

### 2.4 Tools

- All new verbs added to `tools/src/lib.rs::fuzz_verb` (range 206–209).

### 2.5 Tests

## 3. Deferred (explicitly not in this phase)

| Item | Reason | Next step |
|---|---|---|
| Banking quorum / IOUs | Requires `LedgerService` with branch hosts and a 2-of-3 quorum; larger than one session. | New `sim/src/ledger_service.rs`; start with 2-of-3 and IOU cap. |
| Mirrored criminal records / licenses | Depends on the quorum ledger above. | Replica views + quorum edit difficulty. |
| Mailer hardening (salted hash, multi-turn crack, attachments as files, virus auto-run) | Needs `Account` + file sectors wired into `Mailer`; substantial. | Extend `sim/src/mailer.rs` to use `Account` and `HostFile`. |
| Zombie income cap | Minor; fold into mailer hardening. | Cap per host/day in mailer. |
| Host zones in the RAM arena (zone colors, visibility) | Data model landed; rendering is a GUI pass. | Color cells by `zone_at`; gate Private behind Access*. |
| Account cracking verb | Needs multi-turn interruptible state; folds into `DeckCrack`. | Extend `DeckCrack` to target an account. |
| Remote admin allowlist | Depends on cracking + zones. | Add `remote_admin_allowlist` to Host. |

These are the “services” half of v0.7. They are deliberately deferred
because they change the ledger and mailer, which are the highest-risk
surfaces in the sim; doing them in a separate, focused pass keeps the
host-dungeon data model reviewable.

## 6. Risks

| Risk | Mitigation |
|---|---|
| Hosts become a UI puzzle, not a game | Tie zones/files to contracts and loot; keep verbs logged and replayable |
| Remote admin too easy | Gate behind allowlist + multi-turn crack + log scrubbing |
| Ledger quorum complexity | Start with 2-of-3; IOU cap; nightly audit |
| Old saves break | `#[serde(default)]` on all new fields; replay hash tests |
| Scope creep into PDS | Explicit non-goal until OSS selected; bridge stays separate |

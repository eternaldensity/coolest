# 10 — Synthesis: What 2006 + 2024 Add to the 2005 Design

Sources:
- `Coolest.odt` (2005, ~3478 paras) — base fantasy: 4 modes, RAM/disk grids, alignment, streaming GUIDs.
- `Hacker simulator 2006.odt` (241 paras) — dual-network plot, concrete HW/devices, CLI + UI layout.
- `hacker-game-design.txt` (2024, 2.8KB) — survival loop + card/dice/resource Deck.

## 2006 ideas adopted (robustness fixes)

1. **Oldnet vs Betanet (plot + topology).**
   2005 had vague “protocol gaps”. 2006 makes it load-bearing:
   Oldnet = wired, decaying, illegal/personal; Betanet = wireless + laser backbone,
   gov-regulated, commercial, encrypted, range-gated, backbone tolls.
   Cross-network bounce needs right HW+SW. This gives the “why hack” and the
   “why two graphs” in one move. Adopted in `04-network-services.md`.
2. **Trace as timer with bounce + logs.**
   2005 traced to `at`-computer vaguely. 2006: every hop adds trace-time,
   logs on every transit host record you, `tracer` vs `scrambler/monitor`
   programs + `behaviour/connection/email filters` + `patches` counter vulns.
   Adopted in `03-cyberspace-databattle.md`. Makes stealth quantifiable.
3. **Vuln / exploit / patch cycle + HW model.**
   2005 had generic crackers. 2006 lists: `cpu/memory/drives/modems(wired/wireless/laser)`,
   `boot order, on/off, add/remove HW, destroy`, install time (pay to rush),
   `drivers, user DB, logs, startup, filters, patches, memberlists, catalogues`.
   File transfer capped by min(modems along path). Your own box hackable.
   Adopted in `04` + `07-items-combat.md`. Kills “magic numbers” hand-wave.
4. **Scope cuts that save the project.**
   - NPCs: ambient traffic + agenda + reactions only, **no hunger checks** (2006 explicit).
   - Vehicles: fast-travel to named nodes, no driving sim.
   - Nav: walk anywhere + click-to-walk in Live view; arrows stay in console (focus pain noted).
   Adopted in `05-ai-alignment-crime.md` + `09-ux-roadmap.md`.
5. **Concrete CLI + panes + zoom levels.**
   `ls/cd/mkdir/search/mv/view/delete/upload/download/help`, `logon` (local) vs
   `login` (remote), `select/connect/login/logout/disconnect/show connections/logins`
   with hop-count args; dual consoles share HW; character console when off-device
   (`list/use/drop/take`). Panes: console bottom, status left, actions centre-top
   (mem/cpu/time-remaining/trace-time), notify top-right, map top-right with
   World→Continent→Region→City→Live zooms. Single-window constraint kept.
   Adopted in `08-architecture-tech.md`.
6. **Spam/zombie economy + email trojans + crash viruses.**
   Gives early illicit income before bank heists. Adopted in `03`/`04` with caps
   so it doesn’t inflate ledger.

Rejected from 2006: letter-at-a-time cracking called “silly” — replaced by
multi-turn skill-gated crack with progress + interrupt (keeps tension, drops tedium);
explosive HW kept as plot device only, not craftable v1.

## 2024 ideas adopted (fills 2005’s missing loop + numbers)

1. **Survival pressure as tutorial driver.**
   Start: cheapest PC + net + firewall, small bank, no income, `food + mood` decay
   → game over on empty. Order food/meds online, pay for shows/cute videos to prop mood,
   take online programming jobs that cost mood + CPU. This is M0 playable in `09`:
   forces routing, shopping, job, and Deck use in 15 min. Mood/food map to
   `hunger/sleepy/mindpower` drains, not new bars — no parallel needs system.
2. **Paired Deck stats (maps to Mind).**
   `Dedication↔Sway, Focus↔Distract, Stability↔Disturb, Courage↔Fear, Clarity↔Confuse`.
   Implemented as Deck-only derived stats from `comp_literacy/mindpower/conscience`:
   e.g. Focus = `comp_literacy`, Stability = `toughness+patch level`. Attacks target
   the negative pole next-turn only (keeps 2005 alignment + 2024 tempo).
3. **Dice + card effects (concrete Deck resolution).**
   2005 had “20 blows/sec” with no formula. 2024 gives next-turn effect table:
   skip-card if focus∤2/3, DoT to Stability, ban die N, random-target stacking,
   −N to rolls, decoy zero, damage-per-roll-used, downgrade; plus heals, +N,
   extra roll, tank/reflect/splash-half, cancel/avoid, load/copy/skip/upgrade.
   Adopted as `Mod` effects in `03`: small closed set, testable TTK.
4. **Resource-producing creatures (economy ↔ combat link).**
   `optimized loop / data management / advanced algorithm` etc. Jobs require N units;
   manual slow, creatures faster + free player, higher tier = faster but more CPU/RAM,
   1-2 types each. In Deck, some cards produce (×rate if type matches), some consume
   to fire, some consume-all to scale. This ties jobs, loadouts, and fights together
   and justifies CPU as deck cost. Adopted in `03`.
5. **Dev process note kept verbatim:** “Keep it as simple as possible, add one thing at a time.”
   Enforced in `09` slices.

Rejected from 2024: run-ending on mood-empty as hard game-over — softened to
heavy debuff + job lockout (avoids death-by-sadness frustration); “cute program
creature” aesthetic optional skin, mechanics retained.

## Net effect on robustness

- 2005 gave *space* (grids, guids, alignments). 2006 gives *friction*
  (trace, logs, tolls, ranges, install times, filters). 2024 gives *pressure + numbers*
  (food/mood clock, paired stats, card table, resource loop).
- Together: a 15-minute loop (eat → job → hack → dodge trace → sleep) that can be
  built first and used to tune everything else — which 2005 lacked.
